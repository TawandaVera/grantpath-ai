### **B. State Determination Logic**

```python
def determine_state(score, eligibility, days_to_deadline):
    # Rule 1: Auto-DECLINE if not LLC eligible
    if not eligibility["llc_eligible"]:
        return "DECLINE", "Not LLC eligible"
    
    # Rule 2: Auto-DEF if <30 days to deadline
    if days_to_deadline < 30:
        return "DEF", f"Only {days_to_deadline} days remaining"
    
    # Rule 3: Score-based classification
    if score >= 80:
        return "GO", "Strong match"
    elif score >= 60:
        return "PREP", "Good match with preparation needed"
    elif score >= 40:
        return "DEF", "Significant gaps identified"
    else:
        return "DECLINE", "Below minimum threshold"
```

## **3. ASSESSMENT WORKFLOW**

For each grant from JobsRaw:

### **Step 1: Mandate Alignment Assessment (40 points)**
```text
For each of 5 mandate areas (8 points each):
- Read grant description, eligibility, objectives
- Check for keywords/phrases per matrix
- Assign points (0-8) per area
- Document evidence for each point
```

### **Step 2: Eligibility Fit Assessment (30 points)**
```text
LLC Eligibility Check (15 points):
- Explicit LLC mention: 15 pts
- "For-profit" or "private sector" allowed: 10 pts
- Unclear but not excluded: 5 pts
- LLCs excluded: 0 pts → auto-DECLINE

Focus Area Alignment (15 points):
- Direct match to GHIS focus: 15 pts
- Partial match: 10 pts
- Peripheral match: 5 pts
- Mismatch: 0 pts
```

### **Step 3: Deadline Feasibility (20 points)**
```text
Days until deadline assessment:
- >180 days: 20 pts
- 90-180 days: 15 pts
- 30-89 days: 10 pts
- <30 days: 0 pts → auto-DEF
- Rolling: 15 pts (requires research/development time)
```

### **Step 4: Geographic Match (10 points)**
```text
GHIS Primary Markets: US National, California, Texas, Global Health (LMIC focus)
- Exact market match: 10 pts
- Partial overlap: 7 pts
- Adjacent market: 4 pts
- No overlap: 0 pts
```

### **Step 5: Generate 3-Sentence Brief**
```text
Template:
Sentence 1: [WHAT] This [grant name] from [funder] offers [amount range] for [focus area].
Sentence 2: [WHY FIT] It aligns with GHIS's [specific mandate areas] through [key alignment points].
Sentence 3: [WHAT'S NEEDED] To pursue this, we need [preparation work] and should [next steps].
```

### **Step 6: Gap Analysis**
```text
Identify:
1. Missing mandate alignments (which of 5 areas not covered)
2. Eligibility concerns (LLC restrictions, focus mismatches)
3. Timeline constraints (deadline vs. preparation time)
4. Geographic limitations
5. Resource requirements (forms, partnerships, etc.)
```

## **5. DATA SCHEMA (Assessments Table)**

```sql
CREATE TABLE GrantAssessments (
    assessment_id UUID PRIMARY KEY,
    grant_fingerprint CHAR(32) REFERENCES JobsRaw(grant_fingerprint),
    assessment_timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    -- Scores (0-100 scale)
    mandate_alignment_score INT,
    eligibility_fit_score INT,
    deadline_feasibility_score INT,
    geographic_match_score INT,
    total_score INT,
    
    -- State classification
    state VARCHAR(10),  -- GO, PREP, DEF, DECLINE
    state_reason TEXT,
    
    -- Mandate area breakdown
    mandate_scores JSON,  -- {"health_systems": 8, "workforce": 7, ...}
    
    -- Brief components
    brief_what TEXT,
    brief_why_fit TEXT,
    brief_what_needed TEXT,
    
    -- Gap analysis
    gaps JSON,  -- [{"area": "eligibility", "gap": "requires academic partner", "severity": "medium"}]
    
    -- Automatic filters applied
    auto_filters JSON,  -- {"llc_check": "passed", "deadline_check": "passed"}
    
    -- Recommendations
    recommended_actions JSON,  -- ["develop LOI template", "identify academic partner"]
    estimated_prep_time_days INT,
    
    -- Audit trail
    assessor_version VARCHAR(20),
    scoring_matrix_version VARCHAR(10),
    notes TEXT,
    
    INDEX idx_state_score (state, total_score DESC),
    INDEX idx_timestamp (assessment_timestamp DESC)
);
```
