### **Step 2: Writer Matching Algorithm**

```python
def assign_writer(grant_package, available_writers):
    # Calculate complexity score
    complexity = calculate_complexity(grant_package)
    
    # Filter writers by:
    # 1. Required expertise level
    # 2. Current workload (< 80% capacity)
    # 3. Subject matter expertise match
    # 4. Historical success rate with similar grants
    
    eligible_writers = [
        w for w in available_writers 
        if w.level >= complexity.writer_level
        and w.current_hours + complexity.estimated_hours <= w.weekly_capacity
        and w.specialties.intersection(grant_package.mandate_areas)
    ]
    
    # Priority: Expertise match → Success rate → Availability
    return sorted(eligible_writers, 
                  key=lambda w: (
                      len(w.specialties.intersection(grant_package.mandate_areas)),
                      w.success_rate,
                      w.current_hours
                  ), reverse=True)[0]
```

## **8. DATA SCHEMAS**

### **Writer Assignment Table:**

```sql
CREATE TABLE WriterAssignments (
    assignment_id UUID PRIMARY KEY,
    grant_fingerprint CHAR(32),
    writer_id VARCHAR(50),
    assigned_at TIMESTAMP,
    accepted_at TIMESTAMP,
    complexity_level ENUM('simple', 'moderate', 'complex'),
    estimated_hours INT,
    actual_hours INT,
    milestone_dates JSON,  -- {"kickoff": "2024-11-25", "draft1": "2024-12-16", ...}
    current_milestone VARCHAR(50),
    status ENUM('assigned', 'accepted', 'in_progress', 'completed', 'cancelled'),
    quality_score DECIMAL(3,1),
    reassignment_count INT DEFAULT 0,
    notes TEXT
);
```

### **Submission Tracking Table:**

```sql
CREATE TABLE SubmissionTracking (
    tracking_id UUID PRIMARY KEY,
    grant_fingerprint CHAR(32),
    submitted_at TIMESTAMP,
    submitted_by VARCHAR(100),
    submission_method VARCHAR(50),  -- portal, email, mail
    confirmation_proofs JSON,  -- {"screenshot_url": "...", "email_id": "...", "ref_number": "..."}
    acknowledgement_received BOOLEAN,
    acknowledgement_date DATE,
    decision_eta DATE,
    actual_decision_date DATE,
    decision_outcome ENUM('awarded', 'declined', 'waitlisted', 'pending'),
    decision_amount DECIMAL(12,2),  -- Actual amount if awarded
    decision_feedback TEXT,
    followup_log JSON,  -- Array of follow-up attempts and responses
    lessons_learned TEXT,
    success_factors JSON,
    
    -- Predictive analytics
    predicted_outcome ENUM('awarded', 'declined'),
    prediction_confidence DECIMAL(4,3),
    similar_grants_reference JSON,
    
    INDEX idx_decision_eta (decision_eta),
    INDEX idx_outcome (decision_outcome, submitted_at)
);
```
